# Dashboard CER — Avellino

Piattaforma web per la consultazione degli output del modello RECMOP
sulle Comunità Energetiche Rinnovabili, applicata al Comune di Avellino.

Progetto di tirocinio — LabGIS, Università degli Studi di Salerno.

## Tecnologie

- PostgreSQL + PostGIS (base di dati spaziale)
- FastAPI / Python (server e API)
- Leaflet + Chart.js (interfaccia web)

## Struttura

- `backend/app/` — server FastAPI
- `backend/preparazione/` — script di caricamento dati
- `frontend/` — interfaccia web
- `docs/` — documentazione di progetto
